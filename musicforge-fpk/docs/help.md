# MusicForge for fnOS — 使用与授权引导

## 1. 首次启动

1. 应用中心安装完成后启动 MusicForge（自动生成随机访问 token）；
2. 查看 token：应用数据目录 `data/.token`，或应用日志 `data/logs/server.log`
   首启段落（明文展示一次）；
3. 浏览器访问 `http://127.0.0.1:8787`（fnOS 本机）——对外访问请先在 fnOS
   反代/网关中配置，并自行评估暴露风险（R22：默认仅回环）。

## 2. 三目录授权（fnOS 权限模型）

应用访问你的文件必须由管理员显式授权（**系统设置 → 应用 → MusicForge →
+文件夹**）：

| 目录角色 | 授权要求 | 用途 |
|---|---|---|
| 音乐库（扫描源） | **只读** 即可 | 扫描 / 重复清理（dry-run 全功能） |
| 输出目录 | **读写** | 转换 / 整理的产物输出 |
| 回收站 | **读写** | Trash 机制（崩溃安全依赖） |

未授权目录：扫描会明确报告 `MF-DIR-NOT-AUTHORIZED`（含授权引导文案），
绝不会静默跳过。

## 3. 数据与升级

- 数据目录 = 应用自有空间：`library.db`、日志、token 都在这里（X16 位置铁律：
  本地存储，非网络挂载）；
- **覆盖安装**保留数据目录（库结构走 `PRAGMA user_version` 迁移）；
- **卸载**默认保留 `/data`（数据安全优先），由你手动清理。

## 4. 安全立场（不变）

- 服务端**零网络出站**（CI 断言铁律）；
- 无默认口令（token 随机生成）；
- 默认绑定回环地址；
- 格式迁移插件独立分发、默认禁用、需 ACK 确认（`no bundled secrets`）。
